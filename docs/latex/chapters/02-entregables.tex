\section{Herramientas}
\begin{itemize}
  \item Documentación: \LaTeX{} (MiKTeX, compilación con \texttt{latexmk}) y Markdown como documentos de trabajo.
  \item Diagramas y mockups: PlantUML 1.2026.10. Los archivos fuente \texttt{.puml} se conservan junto a las imágenes.
  \item Implementación: Python 3.12 o superior, Django 5.2 LTS, SQLite y APScheduler.
  \item Control de versiones: Git y GitHub.
\end{itemize}
